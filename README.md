# Mo-Vistas

**Discover Odisha, beyond the ordinary.**

Mo-Vistas is a mobile-first tourism discovery website concept that helps travellers discover lesser-known heritage and nature destinations in Odisha, explore local culture, and find community-based travel experiences. The long-term goal is to help more tourism income reach village homestays, local guides, cooks, artisans and small businesses.

## Features in this starter

- Responsive landing page for desktop and mobile
- Search destinations by name, region or experience
- Filter destinations by Heritage, Nature and Culture
- Destination cards with travel-planning notes
- Community partnership section
- Accessible navigation and reduced-motion support
- No framework, build step or API key required

## Run it locally

1. Download or clone this repository.
2. Open `index.html` in a browser.

For local development, you can also run a simple server from this folder:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.


## Current demo destinations

The included destination cards are starter examples to demonstrate the interface. They are **not a verified travel database**. Before public launch, research and confirm destination information, travel routes, entry fees, opening hours, accessibility, safety, seasonal restrictions, accommodation details and local contacts with trustworthy sources and community partners.

## Roadmap

- [ ] Verified route and transport guidance
- [ ] Local homestay and guide listings with consent
- [ ] Local food and small-business directory
- [ ] Community-submitted places with a moderation process
- [ ] Map integration and distance estimates
- [ ] Odia and English language support
- [ ] Contact and enquiry forms
- [ ] Clear privacy policy and listing verification dates

## Project principles

- Credit local knowledge and contributors.
- Ask permission before publishing personal contact details, photos or community stories.
- Keep listings accurate and display when information was last verified.
- Avoid presenting culturally sensitive places as attractions without community guidance.
- Do not accept bookings or payments until secure, trustworthy processes are implemented.

## Tech stack

HTML, CSS and vanilla JavaScript. Google Fonts are loaded remotely; the site falls back to system fonts if unavailable.
